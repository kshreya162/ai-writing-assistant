# AI Writing Assistant

A simple AI writing assistant built with **Python, LangChain, Google Gemini, and Streamlit**.

## Features

- Blog writing
- Email drafting
- Code explanation
- Social media post generation
- Adjustable temperature
- Custom prompt templates

## Tech Stack

- Python
- LangChain
- Google Gemini
- Streamlit
- UV

## Run Locally

```bash
uv sync
